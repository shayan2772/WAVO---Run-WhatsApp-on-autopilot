Everything you need

One gateway. Every WhatsApp capability.

From a simple text message to bulk campaigns, groups, channels, and AI-driven automation — all behind one clean REST API and a modern dashboard.

REST API + Webhooks

Full WhatsApp API over HTTP with real-time webhooks, HMAC signatures, and optional smart pre-dispatch filters so you only get the events you care about.

Multi-Session Ready

Run many WhatsApp accounts concurrently on a single instance, each with its own proxy, webhooks, and API-key scoping.

Rich Messaging

Text, images, video, audio, documents, reactions, and bulk sends — with delivery and read-receipt tracking baked in.

Groups & Channels

Create and manage groups, broadcast to WhatsApp Channels/Newsletters, and organize chats with labels.

Enterprise Security

API-key auth with roles, CIDR whitelisting, rate limiting, audit logging, a Docker socket proxy, and non-root container execution.

Modern Dashboard

A React UI for sessions, webhooks, API keys, and live chats — bundled into the API image and served on the same port.

From zero to sent

Live in four steps

01

Spin up the stack

One docker compose up and you have the API, dashboard, and Swagger docs running. Config is auto-generated on first run.

02

Create a session, scan QR

POST a session, start it, fetch the QR code, and scan it with WhatsApp. You're linked in seconds — repeat for every account.

03

Send & receive

Fire messages through the REST API and stream inbound events to your server via signed webhooks — with optional smart filters.

04

Scale & automate

Add PostgreSQL, Redis, and S3 via compose profiles. Wire n8n workflows or let AI agents drive WhatsApp over MCP.

Developer-first

An API that gets out of your way

Clean, predictable HTTP endpoints secured by API keys. Interactive Swagger docs ship in the box. Every route is documented, versioned, and yours to self-host.

  • API-key auth with roles & per-session scoping — pass via header, done.
  • Swagger UI at /api/docs — explore & test live.
  • Engine choice — whatsapp-web.js or Baileys via one env var.
send-message.sh 200 OK 
# Create a session
curl -X POST http://localhost:2785/api/sessions \
  -H "X-API-Key: $KEY" \
  -d '{"name":"my-bot"}'

# Start it & grab the QR to scan
curl -X POST .../sessions/{id}/start
curl .../sessions/{id}/qr

# Send a message
curl -X POST .../messages/send-text \
  -H "X-API-Key: $KEY" \
  -d '{
    "chatId": "628123456789@c.us",
    "text": "Hello from OpenWA!"
  }'
